# Custom U-Net Architecture for Image Segmentation

## Overview
This project implements a complete U-Net architecture in PyTorch for semantic image segmentation using the Oxford-IIIT Pet Dataset.

## Features
- Custom U-Net implementation from scratch
- Modular design (DoubleConv, Encoder, Decoder, Bottleneck)
- Training and evaluation pipeline
- Segmentation mask prediction and visualization

## Tech Stack
- Python
- PyTorch
- Torchvision
- NumPy
- Matplotlib
